# Decision Records

Use ADRs for decisions that affect reproduction claims.

Create a new file from `../templates/decision_record.md` when:

- an OpenSGG implementation is accepted or rejected as official-compatible
- a checkpoint is trusted, rejected, or considered partial
- an evaluator mismatch is discovered
- a baseline is marked deferred
- a PR scope is changed from reproduction to audit/smoke/gap analysis

ADRs should be short, evidence-linked, and reversible if better evidence appears.
