# Path selection and rewriting for the relational-emergence extraction (issue #113).
#
# Consumed by `git filter-repo --paths-from-file`. Literal paths and the
# trailing-slash directory forms select history; the rename lines at the end
# rewrite the selected paths into the research repository layout.
#
# The rename separator is '==>' with NO surrounding whitespace: filter-repo
# splits on the literal and does not strip, so 'A/ ==> B/' would leave a
# trailing space on the old name and be rejected as a mismatched rename pair.
#
# Renames compose in order and apply to already-renamed paths, which is why
# there is no separate `experiments/phase1/` rule: it cannot coexist with the
# package rename, so those drivers land at src/relational_research/experiments/.
