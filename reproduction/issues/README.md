# Issue-Driven Baseline Work

Every baseline starts from an issue. The issue is the contract for the work and
the place where success and failure conditions are made explicit before running
commands.

Use `baseline_reproduction_issue.md` for each baseline.

The issue must identify:

- official paper and repository
- target task and metric
- checkpoint source and checksum
- config and preprocessing assumptions
- evaluator/protocol requirements
- OpenSGG implementation gaps
- success and failure conditions
