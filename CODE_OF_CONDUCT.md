# Code of Conduct

OpenSGG is a research codebase. Keep discussion technical, specific, and
respectful.

Expected behavior:

- focus on evidence, reproducibility, and clear engineering tradeoffs,
- separate people from code and experimental results,
- disclose uncertainty around baselines, metrics, and checkpoints,
- avoid harassment, personal attacks, and misleading claims.

Maintainers may edit or remove comments, issues, or pull requests that violate
these expectations.
